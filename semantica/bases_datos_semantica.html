Concepto y Tipos de Bases de Datos

Bases de Datos Relacionales (RDBMS)

Una base de datos relacional es una coleccion de informacion perteneciente a un mismo contenido o problema que organiza la informacion de manera clara en ficheros. Para ello, usa tablas con filas y columnas para tener una clara organizacion de esa informacion. Entre todos sus ejemplos, se encuentra MySQL o PostgreSQL

Bases de Datos No Relacionales (NoSQL)

Las bases de datos NoSQL guardan datos no estructurados o semiestructurados, como documentos, clave‑valor o grafos, ofreciendo gran flexibilidad. Ejemplos comunes: MongoDB, Redis, Cassandra.

Estructura de una Base de Datos Relacional

  • Tablas (Entidades):Estructuras donde se organizan los datos
  • Campos (Atributos):Columnas que definen la tipologia de la informacion
  • Registros (Tuplas):Filas que contienen cada instancia concreta de datos
  • Claves primarias (Primary Keys):Identificadores unicos de cada registro

Relaciones entre Tablas

  • Relacion 1:1 (Uno a uno): Un registro se relaciona con solo uno en otra tabla.
  • Relacion 1:N (Uno a muchos): Un registro se relaciona con muchos en otra tabla.
  • Relacion N:M (muchos a muchos): Muchos registros se relacionan con muchos en otra tabla, usando una tabla intermedia.

Clave Foránea (Foreign Key): Es un campo que conecta dos tablas, obligando a que el valor exista en la tabla relacionada. Garantiza que las relaciones anteriores (1:1, 1:N, N:M) sean coherentes y evita datos que no tengan correspondencia.

Glosario de terminos

  • SQL:Lenguaje estándar para definir, consultar y manipular datos en bases de datos relacionales. Incluye sublenguajes como DDL (definición), DML (manipulación), DCL (control de permisos) y TCL (transacciones).
  • SGBD:Software que almacena, organiza y gestiona bases de datos. Controla la integridad, la concurrencia, las transacciones, el acceso de usuarios y las copias de seguridad. Ejemplos: MySQL, PostgreSQL, SQL Server, Oracle.
  • Normalizacion:Proceso de organizar tablas y atributos para reducir redundancia, evitar inconsistencias y mejorar la integridad de los datos. Se basa en reglas llamadas formas normales (1FN, 2FN, 3FN, etc.).
